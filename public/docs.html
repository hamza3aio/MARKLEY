Deploy in 10 minutes

  1. Run database/schema.sql, rls.sql, seed.sql in Supabase.
  2. Enable Email auth + Confirm email. Set Site URL to your Vercel URL.
  3. Import hamza3aio/MARKLEY in Vercel. Output dir: public.
  4. Set env: SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY, APP_URL.
  5. Deploy. Verify /api/config never leaks the service key.

Full steps: docs/VERCEL_DEPLOY.md and docs/SUPABASE_SETUP.md in the repo.
